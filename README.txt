PDF FÁCIL - VERSÃO 1

O que esta versão faz:
- Abre arquivos PDF no navegador.
- Permite arrastar e soltar um PDF.
- Funciona em celular e computador.
- Pode ser instalada como PWA em navegadores compatíveis.
- Não possui login, banco de dados ou servidor.
- O arquivo selecionado é aberto localmente pelo navegador.

COMO PUBLICAR GRATUITAMENTE:
1. Crie uma conta no GitHub.
2. Crie um repositório público, por exemplo: pdf-facil.
3. Envie todos os arquivos desta pasta para o repositório.
4. No GitHub, abra Settings > Pages.
5. Em Source, escolha Deploy from a branch.
6. Selecione a branch main e a pasta / (root).
7. Salve e aguarde a publicação.
8. O GitHub fornecerá o endereço do site.

COMO INSTALAR NO ANDROID:
1. Abra o endereço publicado no Chrome.
2. Use o menu do navegador.
3. Escolha "Instalar app" ou "Adicionar à tela inicial", conforme aparecer.
4. O PDF Fácil aparecerá como aplicativo.
